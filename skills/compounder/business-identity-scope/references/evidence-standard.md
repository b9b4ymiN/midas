# Layer 0 Evidence Standard

Use the shared claim language when available: FACT, DERIVED, MANAGEMENT_CLAIM, ESTIMATE, ASSUMPTION, INFERENCE, UNVERIFIED.

For framing claims, preserve four evidence roles:
- **ECONOMIC:** revenue, customer, margin, investment, contracts, usage.
- **BEHAVIORAL:** purchase occasion, alternatives considered, retention, customer adoption.
- **STRATEGIC:** management intent, capital commitment, organizational changes.
- **CAPABILITY:** demonstrated technology/operating competence and transfer evidence.

## Scope confidence
- HIGH: multiple independent evidence roles converge and alternatives are weak.
- MEDIUM: candidate frame explains current economics but one important boundary remains uncertain.
- LOW: competing definitions materially change the downstream market/competitor set and evidence does not adjudicate them.

Every candidate frame must include **disconfirming evidence**: what observation would make this framing wrong?
